A chess engine in a single 4,082-byte Python file: 0x88 board, negamax with alpha-beta and iterative deepening on a fixed node budget, transposition table, quiescence search, and material plus piece-square evaluation. Pure stdlib, deterministic, no model calls.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8090 MAKEFUN_TRIAL_SEED=practice-0 python3 -P -s main.py
```
